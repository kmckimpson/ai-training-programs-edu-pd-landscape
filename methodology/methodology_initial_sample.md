# \# Methodology: Initial Sample

# 

# \## Dataset Size

# 40 papers

# 

# \## Time Window

# 2023–2026

# 

# This time window was selected because widespread adoption of generative AI tools in education accelerated beginning in late 2022 and early 2023.

# 

# \## Data Collection

# 

# The initial dataset was constructed using Google Scholar discovery searches targeting early research discussions about artificial intelligence in education.

# 

# Representative search queries included:

# 

# \- "AI in education"

# \- "generative AI education"

# \- "artificial intelligence education"

# \- "large language models education"

# 

# Results returned by Google Scholar were manually reviewed and exported into a structured dataset.

# 

# For each record the following metadata fields were captured when available:

# 

# \- Title  

# \- Abstract snippet  

# \- Authors  

# \- Publication year  

# \- Source repository  

# \- Article URL  

# 

# Duplicate records and inaccessible papers were removed.

# 

# \## Classification

# 

# Each paper was manually classified into a single primary topic category based on the dominant research focus visible in the title and abstract.

# 

# The classification taxonomy included the following categories:

# 

# \- Academic Integrity \& Governance  

# \- AI Integration \& Educational Transformation  

# \- Assessment \& Learning Analytics  

# \- Teacher Workflow Support  

# \- Interactive \& Experiential Learning  

# \- Student Support \& Accessibility  

# \- Instructional Personalization  

# \- Digital Learning Infrastructure  

# \- Institutional Operations  

# 

# When papers addressed multiple themes, the category representing the primary analytical focus of the paper was selected.
